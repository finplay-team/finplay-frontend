# 정책 결정표 — 기획서 "미정" 항목

기획서에서 `[미확정]`/`[확인 필요]`로 남아 있던 항목을 백엔드 구현이 가능하도록 결정한 표.
값은 권장안이며, 대부분 관리자 설정값(config)으로 빼서 운영 중 조정 가능하도록 설계한다.

## 1. 계좌 · 자산

| 항목 | 결정 | 근거 |
|---|---|---|
| 시드머니 | **계좌별 1,000만원** (확정) | 사용자 확정. `accounts.seed_amount = 10,000,000` |
| 계좌 구조 | 주식/코인 **완전 분리**, 이체 불가 | 시세·시간·변동성이 달라 평가 시점·랭킹 의미가 흐려지는 것을 구조적으로 차단 |
| 등급·포인트 | 도입 안 함 | 랭킹으로 일원화 |

## 2. 랭킹

| 항목 | 결정 | 근거 |
|---|---|---|
| 산정 기준 | **수익률(%)** — `(총평가 − 투자원금) / 투자원금`. 투자원금 = 시드 + 튜토리얼 보너스 | 튜토리얼 보상으로 유저별 원금이 달라지므로 절대액 대신 수익률로 공정 비교 (기획서 4-5의 의존관계 규칙 적용) |
| 집계 주기 | **일 단위 스냅샷 (매일 00:00 KST 배치)** | 실시간 갱신 대비 공정성·캐시 효율. `rankings` 테이블에 snapshot_date로 적재 |
| 주식/코인 | **각각 산정** | 계좌 분리 원칙과 일치 |
| AI 리포트 기준 | **미실현 포함** (랭킹과 의도적 불일치) | "순위 = 좋은 투자자 아님" 메시지 전달 장치 |

## 3. 튜토리얼 · 보상 (사용자 확정: 시드 % 지급)

| 항목 | 결정 | 근거 |
|---|---|---|
| 튜토리얼 대상 | 모의투자·주식 입문자 전제의 단계형 온보딩 | 첫 매수 → 투자일기 → 분산투자 → 첫 매도 → 양 시장 거래 |
| 보상 방식 | **단계 완료 시 초기지급액의 %를 각 계좌에 보너스 지급** (2% / 3% / 3% / 5% / 5%, 총 18%) | 사용자 확정. 입문 행동에 실질 보상 |
| 완료 판정 | 실제 거래 활동으로 자동 판정 (수동 체크 아님) | `tutorialService.isCompleted` — 거래·일기·보유 데이터 기반 |
| 랭킹 연동 | 보너스는 `bonusTotal`에 누적되어 **투자원금(분모)에 포함** → 보너스가 수익률을 부풀리지 않음 | 랭킹 공정성 유지. 위 2번 수익률 전환의 근거 |

## 4. 주식 시세 처리

| 항목 | 결정 | 근거 |
|---|---|---|
| 데이터 소스 | **미정 (증권사명 노출 금지)** | 랜딩·UI에 특정 증권사명 표기하지 않음. `PriceProvider` 인터페이스로 추상화 |
| 공급 방식 | **장중 지연 시세 + 장 마감 후 당일 데이터 재생 (2안)** | 시연 시간 제약(15:30 이후 정지) 해소. 복기 기능과의 시세-뉴스 연동 유지 |
| 재배포 허용 | **`[법무 확인]` 필요** | 실시간뿐 아니라 지연 시세도 웹 화면 노출(재배포) 허용 여부를 데이터 제공사 약관/법무로 확인해야 함. 미해결 시 **과거 구간 재생 + 종목 익명화**로 회피 |
| 포털 크롤링 | **금지** | 네이버·다음 금융 크롤링은 약관 위반 |

## 5. 코인 시세 처리

| 항목 | 결정 | 근거 |
|---|---|---|
| 데이터 소스 | **업비트(Upbit) API** | 시세 조회 인증 불필요, WebSocket 실시간 무료 |
| 공급 방식 | **실시간 스트리밍** (WebSocket → Redis Pub/Sub → 클라이언트) | 24시간 운영, 실시간 처리 역량의 정상 동작 경로 |

## 6. 거래 정책 (주식)

| 항목 | 결정 |
|---|---|
| 거래 가능 종목 | **코스피200** (범위 관리 + 유동성) |
| 호가 단위 | 가격대별 틱 반영 (한국거래소 기준 테이블) |
| 주문 단위 | 1주 (소수점 미지원) |
| 수수료·세금 | 간이 반영(설정 토글): 매도 거래세 + 위탁수수료 |
| 가격 제한 | 상·하한 ±30% 반영 |
| 장 마감 후 주문 | **예약주문 큐잉** 후 다음 개장 시 처리 |
| 지정가 체결 배치 | **10초** 간격 스케줄러 |

## 7. 거래 정책 (코인)

| 항목 | 결정 |
|---|---|
| 거래 가능 종목 | **원화마켓 거래대금 상위 30** |
| 주문 단위 | 소수점 **8자리**까지 |
| 최소 주문 금액 | **5,000원** |
| 수수료 | 간이 반영(설정 토글): **0.05%** |
| 지정가 체결 배치 | **5초** 간격 (24시간 상시) |

## 8. 인증 · 회원 (기획서 미기재 · 추천 보강)

| 항목 | 결정 |
|---|---|
| 가입 | 이메일 + 닉네임 + 비밀번호(8자↑) + 약관 동의 |
| 로그인 | 이메일/비밀번호 → JWT (mock: localStorage 세션) |
| 가입 시 처리 | 주식·코인 계좌 자동 생성 + 시드머니 지급 |
| 권한 | USER / ADMIN 롤. `/admin`은 ADMIN 전용 보호 라우트 |
| 회원 상태 | ACTIVE / SUSPENDED (관리자 토글, 정지 계정 로그인 차단) |

## 9. 관리자 기능 (기획서 확장 항목 구현)

| 기능 | 내용 |
|---|---|
| 통계 대시보드 | 회원수·계좌수·거래대금·활성 이벤트 |
| 회원 관리 | 목록, 상태 토글(정지/활성) |
| 종목 관리 | 거래 가능 종목 on/off (주식/코인) |
| 미션 관리 | 미션 CRUD, 보상 라벨 설정 |
| 경제 이벤트 | 금리/CPI/실적 등록 + 알림 트리거 (기획서 12장 확장 항목) |
